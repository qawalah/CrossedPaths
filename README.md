# CrossPaths

Did your paths ever cross? Compare two people's location histories (Google Maps Timeline
exports, GPX/FIT/CSV from Strava, Apple Health, Garmin and other apps, Swarm check-ins, or photo GPS) and see every time they were in the same place - consent-gated, self-hosted.

- `server/` - Flask + SQLite server and web client, runs in Docker on a NAS (port 8787)
- `mobile/` - Expo / React Native app (Android; iOS pending)
- `store-listing/` - Google Play screenshots, feature graphic, icon and listing text

Start with `HANDOVER.md`.
