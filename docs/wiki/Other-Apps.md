# Other apps

Any app that exports GPX, KML/KMZ, GeoJSON or FIT works: OwnTracks, GPSLogger, Dawarich, Arc, Komoot, Wikiloc, Polarsteps, car and dashcam apps.

> Pictures are simplified drawings of each screen with the button to press circled in red. Menu names change a little between app versions.

## CSV files

**Step 1.** The file needs a **latitude**, a **longitude** and a **time** column (any common column name works).

**Step 2.** Points without a time can't be compared, so planned routes are skipped.

## Then upload it

Upload the file(s) as they are.

See [Uploading to CrossPaths](Upload.md).
